# Pizzaria Di Napoli

## Objetivos

* Esse projeto foi criado para uma pizzaria fictícia, sendo o site oficial dessa marca
* Foi construído com html e css
* Minha motivação para criar esse projeto foi para aprender e testar um site com várias páginas e meus conhecimentos com html e css.

## Histórico de commits

* **Versão 1 (26/08/2026):** Páginas inicial e cardápio feitas, tanto html como css das mesmas; início do projeto
* **Versão 2 (27/08/2026):** Página história adicionada no projeto (apenas html), que conta uma história fictícia de como a pizzaria teria surgido
* **Versão 3 (13/09/2026):** Finalizadas todas as páginas. Foram adicionadas a página história (css) e as páginas html e css das unidades, que mostra onde teriam as pizzarias espalhadas pelo Brasil
* **Versão 4 (20/09/2026):** Responsividade em todas as páginas do projeto, para ter meu primeiro encontro com as medias queries
